## 🚀 Getting Started

### Absolute Quickest Way (3 steps)

1. **Setup** (Choose your OS)
   ```bash
   setup.sh      # macOS/Linux
   setup.bat     # Windows
   ```

2. **Configure** (Edit .env)
   ```
   GEMINI_API_KEY=your_key_here
   ```

3. **Run** (Choose your UI)
   ```bash
   run.sh        # macOS/Linux → Select 1 or 2
   run.bat       # Windows → Select 1 or 2
   ```

4. **Visit**
   - Web UI: http://localhost:8080
   - Gradio: http://localhost:7860
