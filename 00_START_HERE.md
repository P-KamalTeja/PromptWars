## 🚀 HOW TO RUN

### Step 1: Setup (Choose your OS)

**Windows:**
```bash
setup.bat
```

**macOS/Linux:**
```bash
./setup.sh
```

### Step 2: Configure

Edit `.env` file:
```env
GEMINI_API_KEY=your_api_key_here
```

### Step 3: Run (Choose UI)

**Windows:**
```bash
run.bat
# Select 1 for Web UI (Recommended) or 2 for Gradio
```

**macOS/Linux:**
```bash
./run.sh
# Select 1 for Web UI (Recommended) or 2 for Gradio
```

### Step 4: Open Browser

Visit: **http://localhost:8080**
